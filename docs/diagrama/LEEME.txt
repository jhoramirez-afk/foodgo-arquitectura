Esa propuesta contiene componentes que no se implementaron y no describe el despliegue actual.

Arquitectura actual:
Postman con firma SigV4 -> API Gateway AWS_IAM -> VPC Link -> ALB interno
-> Nginx -> ocho servicios Spring Boot en Docker Swarm.
PostgreSQL conserva ocho bases de dominio; Eureka registra las instancias.
Notificaciones -> SQS -> Lambda Java 21 -> backend privado -> intento persistido.
GitHub Actions, CloudFormation, ECR y S3 coordinan la entrega.

Un manager y un worker no dan alta disponibilidad del plano de control.
PostgreSQL no está replicado. Pagos y avisos son registros académicos.
